## Projects

### 📊 [Layoffs Data Analysis (SQL)](./SQL%20%231%20project)

### 🕸️ [Largest Companies in Pakistan (Web Scraper)](./largest-companies-pk-scraper)
Python web scraper using BeautifulSoup and Pandas to extract and clean company data from Wikipedia, exported to CSV.
